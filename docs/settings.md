# Settings

## Dataset program

The **Settings** tab shows the **dataset program**: every space type Termite knows, with its minimum width.

| Space | Min width (m) |
|---|---|
| living room | 3.5 |
| hallway | 1.2 |
| dining room | 3.0 |
| bedroom | 2.5 |
| bathroom | 1.5 |
| toilet | 0.9 |
| storage | 1.0 |
| entry | 1.2 |
| kitchen | 2.0 |
| laundry | 1.5 |
| Loggia | 1.5 |
| closet | 0.8 |

- **min_width** is the narrowest that space can be in a generated plan.
- **furnitures** shows the furniture Termite uses for that space when you generate a furnished plan.

Every new project starts with this list of spaces.

---

## The Termite bar

The **Termite** bar at the top of the panel opens and closes when you click it. It contains:

| Item | What it does |
|---|---|
| **Notifications** | Messages from Termite, for example when a new version is available |
| **⏹ Stop** | Stops a generation that is still running |
| **↻ Refresh** | Reloads projects, floors and results from the server |
| **Update** | Installs a new plugin version when one is available |
| **Profile** | Opens your account in the [portal](getting-started.md#1-sign-in-to-the-portal) |
| **Generative core version** | The version of the AI model Termite uses |
| **Dataset in use** | The dataset the plans are generated from |

---

## Access token

The plugin stores the access token you entered during installation. To use a new token (for example after you reset it in the portal), install the plugin again and enter the new token.
